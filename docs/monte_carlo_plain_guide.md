# 蒙特卡洛模拟·大白话完整说明

> 本文用尽量少的术语、尽可能多的具体数字，描述本仓库的蒙特卡洛模拟从头到尾是怎么做的。
> 记号约定：`N(0, σ)` 表示均值为 0、标准差为 σ 的高斯（正态）分布随机数。

## 第一部分：基础流水线（Level 1/2 的一维版本）

最终版本是在这条基础流水线上加东西加出来的，先看懂这条。

### 第 0 步：固定不变的参数

- 原子：铯-133，质量 m = 2.207×10⁻²⁵ kg
- AOD 阱（会动的那个）：深度 280 μK（乘玻尔兹曼常数 k_B 换算成焦耳），束腰半径 w = 1.17 μm，初始中心在 x = 2.4 μm
- SLM 阱（不动的那个）：深度 140 μK，束腰 1.17 μm，中心在 x = 0
- 阱的形状是一口倒扣的高斯钟：U(x) = −D × exp(−2(x−c)²/w²)，原子受到的力就是这个函数求导取负
- 原子初始温度：5 μK

### 第 1 步：制备初态 —— 每个"原子"抽两个随机数

要跑多少条轨迹：基线 50 条，正式对比 2000 条。

每条轨迹（= 一个原子）的初始位置和速度：

- **位置**：x₀ = 2.4 μm + N(0, 0.078 μm)。即以 AOD 阱底为中心、σ = 0.078 μm 的高斯分布。这个 σ 不是拍脑袋，是 σ_x = √(k_B·T/(m·ω²))，其中 ω = √(4D/(m·w²)) 是阱底近似成谐振子的振动频率（代入数字是 36 kHz）
- **速度（动能来源）**：v₀ = N(0, 1.77 cm/s)，σ_v = √(k_B·T/m)
- **一道筛选**：算总能量 E = ½mv₀² + U(x₀)（用真实高斯势），只有 E < 0（真的被阱绑住）才保留，否则重抽。5 μK 时几乎全部通过

随机数全部由固定种子（如 20260811）的 numpy 随机数发生器依次产生，整批结果可原样复现。

### 第 2 步：让原子在两口阱里走 600 μs

- 时间切成一小格 dt = 0.05 μs，共 12000 格
- 前 312 μs：AOD 中心按 c(t) = 2.4 × (1 − (3s²−2s³)) 从 2.4 μm 滑到 0（s 是时间比例，头尾速度为零）
- 后 288 μs：AOD 深度按 D(t) = 280 × (1−s)² 降到 0，把原子"倒"给 SLM
- 每一小格干三件事：
  1. 算当前位置两口阱的合力 F(x, t)
  2. 更新位置和速度：x ← x + v·dt + ½a·dt²，再算新加速度 a′，然后 v ← v + ½(a+a′)·dt
  3. **加热踢**（Level 2 起加入）：v ← ±√(v² + 2P·dt/m)，P 是每秒注入的加热功率，由光子散射、光强涨落、光斑指向抖动三部分相加

### 第 3 步：判定有没有被接住

600 μs 走完，算末态能量 E_f = ½mv² − 140μK × exp(−2x²/1.17²)（只算 SLM 这口阱）：

- E_f < 0 → 被 SLM 俘获
- E_f ≥ 0 → 丢了

### 第 4 步：统计

- 俘获率 = 俘获条数 ÷ 总条数
- 加热量 = 末态平均能量 − 初态平均能量

## 第二部分：最终版本（continuous_transfer 统一引擎，对标论文 Fig. 6d）

### 一句话概括

造 4096 个虚拟原子，每个原子放在一口"有瑕疵的"光镊里给它随机一个位置和速度，然后让它们在两口阱之间反复倒手 30 个来回（共 60 次单程转移），每小步 0.0125 μs 算一次力、挪一次位置，中途不断用能量判据检查"还活着吗"，最后数每个时间点还剩多少原子活着。

### 第 0 步：固定不变的参数

- 原子：铯-133，质量 m = 2.207×10⁻²⁵ kg
- SLM 阱（静止，1061 nm 激光）：名义深度 140 μK，束腰 1.17 μm，中心固定在 (0, 0, 0)
- AOD 阱（会动，1055 nm 激光）：名义深度 280 μK，束腰 1.17 μm
- 三维势的形状（每束光）：横截面是高斯钟，沿光轴发散：
  U(x,y,z) = −D / √(a·b) × exp(−2(x²/a + y²/b)/w²)，
  其中 a = 1+((z−s₁)/z_R)²，b = 1+((z−s₂)/z_R)²，z_R = πw²/λ ≈ 4.05 μm（瑞利长度）。
  s₁、s₂ 是"透镜焦点偏移"：AOD 扫频移动光镊时相当于一个柱面透镜，把两束交叉光的焦点沿 z 轴错开 s = 2·z_R·(移动速度)/0.539 m/s
- 初始温度：T₀ = 15 μK（四条曲线统一用这个值；后来和论文对标定出的最佳值是 19 μK）

### 第 1 步：先给每个原子抽 4 个"装置瑕疵"随机数

共 4096 个原子（= 4096 个独立镊子位点）。每个位点抽一次、全程不变：

- SLM 实际深度 = 140 μK × (1 + N(0, 0.114)) —— 11.4% 位点间涨落，论文实测值
- AOD 实际深度 = 280 μK × (1 + N(0, 0.02))
- AOD 实际束腰 = 1.17 μm × (1 + N(0, 0.02))
- 两阱静态对不准：偏移量 = N(0, 0.05 μm)

### 第 2 步：在每个位点里制备初态 —— 每原子 6 个随机数

顺序很重要：**先抽完第 1 步的深度因子，再按这个位点的实际深度**（比如某位点抽到 140×1.09 = 153 μK）算热分布宽度。15 μK、名义深度下：

- x = N(0, 0.191 μm)，y = N(0, 0.191 μm)，z = N(0, 0.938 μm)（z 方向阱更浅更宽，σ 更大）
- v_x = N(0, 3.06 cm/s)，v_y = N(0, 3.06 cm/s)，v_z = N(0, 3.06 cm/s)

抽完检查：动能 + 该位点真实三维势里的势能 < 0 才算数；不合格就在**这同一个位点重抽**（最多 200 次），保证每个位点恰好一个原子。这就是初态制备：4096 个原子 × 6 个数，全部来自固定种子的标准高斯随机数乘以上面的 σ。

（公式：σ_r = √(kT·w²/(4D))，σ_z = √(kT·z_R²/(2D))，σ_v = √(kT/m)，D 用该位点实际深度。）

### 第 3 步：搭时间轴 —— 一个原子要经历什么

四条波形曲线各跑一遍（初态完全一样，公平比较）：

- **手工 200 / 400 / 600 μs** 三种：拾取 = 前 48% 时间 AOD 在 SLM 头顶把深度按 D(s) = 280×s² 升起来（把原子从 SLM 抢过来），后 52% 时间 AOD 中心按 x(s) = 2.4 μm × (3s²−2s³) 把原子搬走 2.4 μm
- **ML 400 μs**：论文里机器学习优化出的轨迹，14 个控制点三次插值（从论文图数字化下来）

每一"轮"的流程（matched 协议，即对标 Fig. 6d 的协议）：

1. **拾取** T μs（T = 200/400/600）：上面的波形，SLM 全程开着
2. **等待** 100 μs：SLM 瞬间关掉（只改势，原子位置速度不动），确认原子独立待在 AOD 里
3. **放回** T μs：拾取波形严格按时间倒放，SLM 重新打开，原子倒回 SLM

重复 30 轮 = 60 次单程转移。全程：400 μs 波形 27 ms，600 μs 波形 39 ms。时间网格 dt = 0.0125 μs，400 μs 波形一轮 72000 小格，30 轮共 216 万小格。

另有一个 extended 变体：每轮在等待后、放回前加一段 375 μm 对角线长途运输（去程 1450 μs + 远端停 54 μs + 回程 1450 μs），这时柱面透镜焦点偏移才真正起作用。Fig. 6d 对比只用 matched。

### 第 4 步：每一小格（0.0125 μs）对这个原子干 8 件事

1. **算力**：两束光的三维势在当前位置、当前 AOD 中心/深度（含位点瑕疵因子、本轮对准抖动）下求梯度，得合力 F = (F_x, F_y, F_z)
2. **半步速度踢**：v += F/m × dt/2
3. **挪位置**：x += v × dt
4. **用新位置、新时刻重新算力**，再**半步速度踢**：v += F′/m × dt/2（velocity-Verlet，能量保持好）
5. **加热踢**：每小格把速度整体放大 v ← v×√(1 + 2P·dt/(m·v²))，确定性地注入功率 P。P 由三部分相加（全部是假设值）：
   - 光子散射：两束光合计每秒散射约 4.23 个光子，每次给 2 份反冲能量
   - 光强涨落：相对强度噪声 10⁻⁸/Hz，按参量加热公式 Γ = π²ν₀²×S 代入阱频 36 kHz
   - 光斑指向抖动：1 pm/√Hz
   - （另有真随机版本：每 4 小格抽高斯随机数 v += (F/m)×√(S·h/2)×N(0,1)，两束光各自独立；指向噪声沿 x 轴按当地力梯度踢；反冲改成三轴各踢 √(2·rec·h/(3m))×N(0,1)）
6. **累积相位**：原子的"量子相位"往前走一小步：φ += η × U(当前位置总势) / ħ × dt，η = 1.3×10⁻⁴（两钟态对光移的相对灵敏度，假设值）
7. **如果这一格落在退耦脉冲内**（matched 用 XY4 序列 = 4 个有限时长 π 脉冲），就把这个原子的量子态（2 维复向量）按精确公式转一小步。微波 Rabi 频率 24.611 kHz，一个 π 脉冲实际持续约 20.3 μs，脉冲期间原子照常运动。脉冲之外的相位积累先记账，到检查点一次性结算成一个 z 旋转
8. **每轮每段换一种对准抖动**：AOD 对准偏移 = 静态偏移 + N(0, 0.01 μm)，每轮重抽；pickup/wait/dropoff（及 extended 三段）各用一条独立随机流，但四条波形共用同一组，保证公平

### 第 5 步：检查点判定 —— 每个原子每轮被查两次"户口"

- **等待段结束**：E = 动能 + 只在 AOD 那口阱里的势能，E ≥ 0 → 原子死了，记下死在哪一轮哪一段
- **放回段结束**：E = 动能 + 只在 SLM 那口阱里的势能，E ≥ 0 → 同样判死
- extended 变体在长途运输三段里也随时查
- **死掉的原子就此出局，不复活、不补新的**；活着的原子带着位置、速度、相位、量子态原封不动进入下一轮

### 第 6 步：4096 个原子全部跑完后统计

- **存活曲线**：S_n = 做完 n 次单程转移还活着的原子数 ÷ 4096，n = 0…60。这就是直接和论文 Fig. 6d 对比的东西
- **拟合**：S_n = p₀ × pⁿ × (1 − e^(−1/(b·n)))（p 是单次存活率，b 描述逐次累积加热）；不确定度用对 4096 个原子重抽样的自助法
- **量子指标**（只对活到最后的原子）：F_avg =（平均 |Tr(U_ideal†·U)|² + 2)/6；相干度 C = |⟨e^(iφ)⟩|
- **对比判据**：四条曲线（手工 200/400/600 + ML 400）分别和从论文 PDF 矢量提取的参考数据（拟合线 + 37 个散点 + 误差条）逐点比较，容差带 ±0.02

### 第 7 步：计算量与验收

- 以 manual_400μs 为例：4096 原子 × 30 轮 × 72000 格/轮 ≈ **88 亿小格**，每格两次三维力求值，Numba 编译后 8 线程并行
- 正式池 4096 条（种子 23003，从未参与调参），扫描池 256 条（种子 23001）；步长收敛用 dt = 0.025 μs 重跑对比
- 最终结论（2026-09-16 标定报告原话）：四条曲线共用一组参数（T₀ = 19 μK、束腰 1.11 μm、AOD 强度噪声 5.75×10⁻⁹/Hz）时，与论文数据的均方根差距降到 2.8–6.5 个百分点，但**四条曲线仍没有全部落进 ±0.02 容差带**——这一未达标事实如实写进了报告

## 整条链回顾

抽 4 个装置随机数（位点瑕疵）→ 按实际深度算 σ、抽 6 个状态随机数（初态制备，E<0 筛选）→ 每轮"拾取—等待—放回"30 轮、每 0.0125 μs 走一格（算力→踢速度→挪位置→再踢→加热踢→积相位→转量子态）→ 每轮两个检查点用能量判存活 → 数存活、拟合曲线、和论文 37 个点对比。所有随机数都来自固定种子，整套结果可逐比特复现。
