# Codex 执行 Prompt：从 Level 2 出发复现论文 SLM→AOD 转移存活率验证

> 生成日期：2026-08-31。
> 对标论文：arXiv 2403.12021v4（*A tweezer array with 6100 highly coherent atomic qubits*）主文 Fig. 6 及 Methods "Atom transfer between SLM and AOD tweezers"。
> 范围界定：**只复现转移存活率（atom survival vs 单程转移次数）**。不包含 IRB 保真度、XY4 动力学解耦、相干性、成像保真度、长距离运输与 zone 架构。
> 出发点：现有 Level 2（AOD→SLM drop-off 一维经典蒙特卡洛，`simulation/level2_joint_transfer/`）。

从现有 Level 2 代码到目标状态，核心差距有四类：**方向反转（drop-off→pick-up）、往返重复序列、论文的两条真实轨迹、以及让存活率降到实验水平所需的损失机制**。下面按依赖顺序逐项列出，每一步都可单独验证、可回退。

## 阶段 0：锁定对标目标

### 1. 数字化论文参考数据与参数表

从论文 Fig. 6d 顶图提取存活率曲线（0.2/0.4/0.6 ms 手工轨迹 + 0.4 ms ML 轨迹，横轴为单程转移次数 n），连同 Methods 参数整理成一张固定参考表：

- SLM 阱深 0.14 mK（k_B 计），AOD 阱深 0.28 mK；
- 分裂移动距离 2.4 μm；
- 手工轨迹：前 48% 时长二次升深 + 后 52% constant-jerk 移动，顺序不重叠；
- ML 轨迹：深度、位置各 14 个控制点，三次插值，同时 ramp-and-move，单程 400 μs，目标为 60 次连续转移；
- pick-up 后 100 μs 等待段（期间 SLM 关闭清除残留原子）；
- SI 数据点：200 μs 单程转移存活率 > 98%。

注意：99.81(3)% 是 IRB 保真度，不属于本次范围；对比对象是顶图的存活率本身。
明确验收标准：例如"模拟的单程存活率落入论文拟合的置信区间内"，或诚实报告差距及归因。

## 阶段 1：把模拟方向反过来（SLM→AOD）

### 2. SLM 阱初态采样器

`level1_transfer_1d/thermal.py` 的 `sample_thermal_initial_state` 目前在 AOD 阱（280 μK）中采样。增加"采样阱可选"，把简谐提议 + 束缚拒绝（E_SLM(x₀,v₀)<0）指向 140 μK、1.17 μm 的 SLM 阱；温度作为可配置参数（论文未直接给转移时刻的温度，需作为标定量保留）。论文说 SLM 从全深绝热降到 0.14 mK 无损失，可默认直接从 0.14 mK 平衡态出发，把绝热预 ramp 留作可选项。

### 3. 俘获判据切换为"束缚于 AOD"

`level2_simulation.py` 的判据现在是末态 SLM 单阱 E_f<0；pick-up 结束（分裂移动完成、原子距 SLM 2.4 μm）时改为

E_AOD = ½mv² + U_AOD(x) < 0，

并且要连同 **100 μs AOD 保持段**（SLM 关闭）一起判定——保持段内逃出 AOD 阱也算失败。把"转移方向"做成引擎参数而不是复制一套代码，drop-off 路径保持原样可跑。

### 4. 新增 pick-up 顺序波形

`waveforms.py` 现在的 `SequentialWaveform` 是"先移动后降深"，而论文手工 pick-up 是**先升深后移动**：前 48% 时长内 AOD 深度从 0 按二次曲线升到 280 μK（中心停在 SLM 上），后 52% 内以 constant-jerk 轨迹移动 2.4 μm。新增 `PickupSequentialWaveform`（二次升深 + constant-jerk 位移，端点速度/加速度为零），端点、单调性、解析导数与有限差分一致性测试照 Level 2 的标准补齐。

### 5. 单次 pick-up 蒙特卡洛基线

复用三池隔离 + CRN + Wilson 区间跑一遍单次 SLM→AOD 转移。预期保守模型下存活率 ≈100%——这是**无害基线**，作为后面每加一项物理时的归因参照。

## 阶段 2：往返序列与"存活率 vs 转移次数"

### 6. 往返序列组合器

把一次完整往返拼起来：pick-up & split → 100 μs 等待（SLM 关，清除残留原子——模拟里对应"只认 AOD 中的原子"）→ SLM 重开 → merge & drop-off（pick-up 轨迹的时间反演，即现有方向）。增加时间反演对称性预检查：保守极限下 pick-up + drop-off 往返应近似回到初态。

### 7. n 次重复转移与存活率曲线

逐 shot 连续模拟最多 N≈60+ 次单程转移，中途丢失即终止并记失败（不换初态），得到 survival(n)。用论文同款公式

S_n = p₀·pⁿ·(1 − e^(−1/(bn)))

拟合（参数 bootstrap 取不确定度），提取每次转移存活率 p，与第 1 步数字化的论文曲线并排画图。这一步在保守模型下 S_n≈1，曲线形状对了但数值对不上——正常，进入阶段 3。

## 阶段 3：复现论文的两条轨迹与时长扫描

### 8. 手工轨迹时长扫描

在 200/400/600 μs 三种单程时长下重复第 7 步，对应论文顶图的灰色系数据组。

### 9. ML 风格轨迹

论文 ML 轨迹是深度、位置各 **14 个控制点、三次插值**（普通 cubic，允许非单调）、ramp 与 move 同时进行。现有 `SplineWaveform` 是 PCHIP 单调样条，需加一个"论文式三次插值"变体并配套防严重过冲的校验选项；优化目标从"单次俘获率"改为"**固定 60 次连续转移的存活率**"，优化器可复用 `optimizer.py` 的 LHS + 精修框架（论文用的在线 ML 优化器本身不必复刻，等价的黑盒优化即可，但要在报告里说明这一替代）。冻结最优后走独立 validation 池，得到 400 μs ML 曲线与手工 400 μs 的配对比较。

## 阶段 4：引入损失机制，把存活率压到实验水平

这是能否"复现数值"的关键，按可归因性逐项加入，每加一项重跑阶段 2/3。

### 10. 打开标定过的加热通道

`noise_heating.py` 已有反冲 / 强度（参量）/ 指向三通道常数功率注入（`velocity_verlet_time_dependent_heating` 积分器也已存在）。按实验水平（RIN 谱、指向噪声谱、1055/1061 nm 两套光路的散射率分别计算）设定默认值，使重复转移中能量逐渐累积、出现真实损失。

### 11. 位点间差异与实验不完美性系综

论文存活率是对 195 个 AOD 阱 × 多次实验平均的。加入逐 shot/逐位点抽样：

- AOD–SLM 相对对准误差分布（论文先用相机对 PSF、再按存活率优化，残余误差即此处分布）；
- AOD 深度标定误差（RF 功率→深度）；
- SLM 与 AOD 束腰失配（1055 nm 与 1061 nm 两套光路；现代码把 w_AOD=1.17 μm 标为假设值，此时应变成带不确定性的参数）；
- 参数 shot-to-shot 抖动。

### 12. （条件触发）升级到 2D 横向模型

若前两步仍不足以达到论文损失水平，把一维径向模型扩成 x-y 二维（分裂移动发生在二维平面，双阱合并/分离的势垒结构与 1D 不同）。柱面透镜按论文说法在该速度下不构成危害，可明确排除在外。

## 阶段 5：统计对比与工程收尾

### 13. 与论文数据的正式对比

复用 `statistics.py` 的 Wilson 区间与配对 bootstrap 比较各时长/轨迹的模拟曲线；对拟合参数 p、b 做两级 bootstrap（模仿论文先 S_n 后 D_n 的做法——虽然 D_n 属于 IRB 部分，这里只做存活率）。产出 survival_vs_transfers.png、拟合参数表、模拟 vs 论文叠加图。

### 14. 诚实差距报告

若经典模型（即使加了噪声与 disorder）仍达不到实验损失水平，定量报告缺口（如"模拟单程存活率 99.99% vs 实验 99.8%，缺口可能来自未建模的 XY4 解耦期间过程/成像损失/三维效应"），不强行调噪声参数凑数——沿用 Level 2 prompt 的防过拟合纪律。

### 15. 配置、CLI、测试与文档

- 新增配置（如 `level2c_pickup_survival.yaml`）与 CLI stage（`preflight / pickup / roundtrip / survival_scan / all`）；
- preflight 增补时间反演检验、双阱时变功-能残差（SLM 深度现在也时变，`work_energy.py` 需推广到两个阱）、步长收敛；
- 测试覆盖波形端点与单调性、判据方向切换、池隔离、CRN、往返可逆性；
- 输出目录结构沿用 Level 2 规范（candidates.csv、validation_shots.csv、metrics.json、summary.md、诊断图及程序化检查）。

## 执行要点

顺序上先做 1–7（纯确定性改造，约等于把现有引擎换个方向跑），再做 8–9（轨迹族对齐论文），最后做 10–12（物理标定，工作量与不确定性最大）。第 5 步和第 14 步的两个"如实报告 100%/差距"检查点是防止中途用验证集调参凑结果的闸门——防过拟合纪律直接沿用 Level 2 prompt 第六节的三池隔离规则。
