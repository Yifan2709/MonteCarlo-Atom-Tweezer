# Level 0：单光镊径向静态数值检查

本项目建立一个静态、一维、经典、单原子的高斯光镊模型，比较 180 μK SLM 和 280 μK AOD 两个独立势阱，并完成解析曲率、数值曲率、有限振幅能量积分基准、velocity-Verlet 轨迹频率和能量误差的自洽检查。它受 arXiv:2403.12021v4 的参数启发，但不是论文复现。

## 模型边界

- `x` 是高斯光束焦平面内的一个径向坐标，不是光轴方向。
- 不模拟论文报告的轴向 5.64 kHz 运动；论文的径向 29.30(4) kHz 仅作量级参照。
- 不模拟 SLM-AOD 交接、深度随时间变化、长距离移动、AOD 柱面透镜效应、二维运动、噪声、量子内态、加热、损失或多原子。
- SLM 与 AOD 调用同一个高斯势和力函数，只通过配置参数及参数来源区分。
- 数值曲率与解析曲率的比较是代码一致性检查，不是独立实验验证。
- 180 μK SLM 与 280 μK AOD 是独立静态势阱，不表示论文某一时刻的重叠转移势。AOD 的 1.17 μm 束腰未由论文单独报告，是后孔径匹配到 SLM 光路的明确假设。

势能零点位于无穷远，只接受初始总能量 `E0 < 0` 的束缚轨迹。程序内部统一使用 SI 单位，输入和报告同时保留微开尔文、微米、原子质量单位、参数来源和 `assumed` 标签。

## 安装和运行

在本目录使用同一个 Python 解释器执行：

```bash
python -m pip install -e ".[dev]"
python -m pytest
python -m level0_static_trap.cli --config configs/default.yaml --trap both --output-dir outputs/level0_static_trap/demo
```

`--trap` 可选 `slm`、`aod`、`both`。配置和 CLI 的相对输出目录均以含 `pyproject.toml` 的项目根目录解析；解析后位于项目 `sources/` 内的输出会被拒绝。CLI 覆盖值及其绝对解析路径会写入 `config_used.yaml`。

## 数值解释

曲率用 `h` 与 `h/2` 两个步长检查收敛。轨迹频率用同方向、线性插值的过零点进行多周期回归；FFT 只作诊断，同时报告原始分辨率 `1/T`。相同初始能量下的非线性周期由一维能量积分计算。

报告严格区分：

- 解析频率与数值曲率频率之差：数值离散化一致性误差；
- 非线性积分频率与小振幅频率之差：有限振幅高斯势的物理软化；
- 轨迹频率与非线性积分基准之差：积分和采样估计误差。

能量误差保存为 `E-E0`、`(E-E0)/U0` 和其绝对值，不除以带符号的负初始能量，也不把有界振荡笼统称为长期漂移。

当前 velocity-Verlet 只保证静态、位置依赖自治力 `F(x)` 下的辛性质。未来扩展到 `F(x,t)` 时，接口、能量解释和辛结构都必须重新审视，不能仅因接口可传函数就宣称支持任意时变势。

## 输出和图像验收

默认 `both` 输出配置副本、共享静态网格、两套轨迹 CSV、严格 JSON 指标、中文汇总和七张至少 200 dpi 的 PNG。每张图都会程序化检查文件大小、可重开性、像素尺寸/方差、数据有限性、数据范围、坐标覆盖、图例数量和 figure 关闭状态。程序化检查不等同于人工或模型视觉审阅，后者是否执行会在 `image_validation.json` 与 `summary.md` 中单独记录。
