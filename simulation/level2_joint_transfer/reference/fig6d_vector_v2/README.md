# Fig. 6d 矢量参考 v2

2026-09-15，替代旧的逐像素颜色追踪参考。

`tools/extract_fig6d_vectors.py` 从论文 `2403.12021v4.pdf` 第 7 页读取独立绘图对象，用矢量刻度线校准坐标。四条拟合路径与 37 个菱形散点分别读取，误差条由独立竖线的上下端点取得。图例标记通过横坐标及形状检查排除。前段被覆盖的标记在 PDF 内仍是独立对象，可以恢复其中心。

- `fig6d_vectors.json`：原始图形坐标、路径和对象索引、散点与误差条、轴标定、源 PDF SHA-256。
- `experimental_marker_centers.csv`：仅论文实际标记位置，手工 200 μs 为 7 点，其余各 10 点。散点不连成稠密曲线。
- `published_fit_comparison_grid.csv`：论文拟合路径按原比较网格读取的长表。
- `published_fit_reference.csv`：默认模拟配置可读取的宽表。仍比较 n=5..31（200 μs）与 n=5..60（其余），避免同时改变比较区间。

没有平滑、单调回归或依据模拟结果重新拟合。拟合路径按 PDF 原有折线段线性读取，保留原图中的拟合模型形状。密集网格只是拟合线采样，不是新增实验数据。

这些坐标来自论文图形，并非作者原始实验数据文件。误差条仅恢复原图几何范围，不自行指定其统计置信口径。拟合值与散点均值可能不同，例如 ML 在 n=60 的拟合线约为 0.6753，散点约为 0.6634，二者不能混用。

旧 CSV 与旧模拟输出保持原样；本次仅用新参考重新评估已存档的模拟。配置中的 ±0.02 是保留的比较容差，不是论文实验误差，也不是矢量坐标读取误差。
