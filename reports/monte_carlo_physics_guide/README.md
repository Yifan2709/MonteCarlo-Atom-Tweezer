- 19–29 页：拾取、等待、放回、控制曲线、时间推进与能量变化。

## 数据与口径

实验对照直接读取 `reports/movement_effects_v1_calibration_20260916/` 内的 `survival_curves.csv`、`point_residuals.csv` 和 `metrics.csv`，最终模型为两批各 4096 原子、共 8192 原子。未重新运行完整标定，也未修改原模拟代码或原始参考数据。

解析势阱曲线、等平均能量分布、相干示意、单步示例均标为教学说明。初态散点使用仓库实际位点束缚采样方法生成，仅用于展示初态分布。单轨迹示例来自仓库 Level 1 历史演示，明确与最终三维标定分开。论文对照页显示散点中心值，误差条定义和原始上下限见归档文件。

最新随机存活标定与较早的有限脉冲相干传播是不同计算路径，本报告不把它们混成一次联合验证。仍保留四曲线未全部达到 ±2 个百分点参照目标的结论。

## 重新生成

使用已提供的 Python（需要 NumPy）和 Node.js（需要 `@oai/artifact-tool`）。生成过程不依赖 `python-pptx`，不绘制或嵌入图表截图。所有图表、表格与文字均为原生可编辑对象。

1. 运行 `prepare_data.py` 生成私有 `.build/data.json`。
2. 设置 `RUNTIME_NODE_MODULES`、`PRESENTATIONS_SKILL_DIR`、`RUNTIME_PYTHON` 为实际运行环境路径。
3. 使用 Node.js 运行 `build_deck.mjs`。若成品已存在，设置 `FINAL_PPTX` 为一个新的绝对输出路径。

`.build/` 存放临时稿、预览和检查记录，按仓库规则不纳入版本控制。
