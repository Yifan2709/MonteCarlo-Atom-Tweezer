# 长距离 AOD 运输：计算前冻结协议

本文件在新研究扫描前写入。基线 1fed6329e95c4439820aff31d644376b817b5d6f；2026-09-17 GitHub branches API 核实远端相同。分支 codex/long-distance-aod-transport，不推送。原有未跟踪报告和历史结果不变。

## 目标与判据

机械存活工程目标 0.99 和 0.999；逐条件二项 Clopper–Pearson 双侧 95% 区间下界达到目标才标支持，跨越为未确定。区间为逐点而非全扫描同时置信。在选出的关键条件使用两个新种子，各 4096 原子；8192 个零损失的下界约 0.99955，不能证明零真实损失。扫描样本用于定位，不用于高可靠性认证。不做单调二分、不插值宣称未计算区间达标。

报告的是有限网格内的条件性机械存活边界，不是全局速度极限或量子信息保真度。记录距离、移动段时间、平均/路径峰值/轴峰值速度、峰值加速度、段内 jerk 和连接处不连续性、完整时间及逐次能量/条件损失。A=单独移动阱，B=静态阱→移动阱→目标静态阱，C=连续重复 A/B，不重采样/重置温度。

## 固定模型和条件性参数

三维有限深高斯势，crossed-AOD 两柱面焦点分别 z_i/zR=tau_i*v_i/w。无透镜用 tau=0 标志，不改变材料声速。质量/波长按物种独立；谐振频率由深度、腰和质量推导。每个实际位点先抽固定深度因子，再在该位点作谐振提议、全高斯 E<0 拒绝采样；这是制备模型，不是无限空间的正则热平衡。逐原子状态连续。

Cs 基准候选：133Cs、AOD 1055 nm、SLM 1061 nm；AOD 280 uK、SLM 140 uK，腰 1.11 um、初温 19 uK（后二者来自短途共同候选，非标定常数）；主扫描无噪声、无不均匀性。距离 270/510/610 um，覆盖旧 Level3 范围。三轨迹：Rb cubic、Yb gamma=1.5625、Yb gamma=1.875。深度对照 140/280/560 uK。tau=0/2/5 us 是显式情景，不冒充装置响应测量；几何主线单轴，独立对照同号/反号双轴。

第二阶段加入同一候选 AOD 单边每 Hz PSD：RIN 5.75e-9/Hz、x 指向 1e-24 m²/Hz；SLM 无噪声近似。静态深度散布 2%、对准 sigma=50 nm 为未标定情景，所有速度共用。噪声通过力扩散施加，不另加运输加热、经验损失或逐速度倍率。

B 协议采用两端共址 200 us 线性功率交接（SLM 与 AOD 交叉渐变），移动结束保持 100 us；不同于旧 2.4 um 短途拾取，也不是已测装置波形。其预测仅对这一明确工程协议成立。另作交接时间/误差对照。重复数至少 1/10/50 单程，交替方向；不把单程当往返。

仅在静止段末用目标单阱 E=K+U<0 判束缚；无穷远势能为零。运动中实验室动能只用于功–能核算，不用来吸收原子。纯匀速验证使用 Erel=m|v-vtrap|²/2+U；加速阱中 Erel 不守恒，倾斜势垒是诊断，不作任意永久损失阈值。有限时间观测不能证明所有负能原子永远安全；记录正能观测时刻与激发阶段分开。

## 计算顺序与收敛

原文/代码审计 → 静态与匀速/谐振解析/力导数/噪声基准 → 原生 Rb/Yb 对照 → 无噪声粗网格 → 机制/重复/敏感性 → 边界附近细网格 → 新种子确认。主机械步长候选 0.1 us，边界 0.1/0.05/0.025 us 逐次减半；若基准不满足则缩小。噪声单独比较 0.2/0.1/0.05 us（不得小于机械步）。保存每点原始 NPZ、参数、控制/种子、源文件哈希、运行日志；失败点保留。

未知实测扫描带宽、频率位置标定、光束半径和轴符号不能编造。tau/T 或 tau*变化率不小时，瞬时透镜只作近似；用传播相位展开的高阶残差约束其适用性，不引入经验速度损失。
