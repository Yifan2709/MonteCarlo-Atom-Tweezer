Product description

The G&H AODF 4085 TeO₂ 750–1064nm Near-Infrared Acousto-Optic Deflector is designed for beam steering and optical scanning across multiple near-infrared wavelengths. It uses TeO₂ as the acousto-optic medium and operates in a shear, off-axis acoustic mode.

The device is specified with horizontal input polarization and vertical output polarization, supporting defined optical integration in near-infrared laser systems. Its operating frequency range and scan angle are specified by wavelength, enabling system designers to match RF drive conditions to the required laser wavelength.

With a 15 mm diameter active aperture, nominal RF power and defined uniformity across bandwidth, the AODF 4085 is suitable for OEM photonics systems requiring controlled near-infrared beam deflection across a broad wavelength range.

Key features

  • Supports near-infrared laser beam steering across the 750–1064nm wavelength range
  • Large active aperture supports integration with wider optical beam paths
  • TeO₂ acousto-optic medium supports efficient near-infrared beam deflection
  • Wavelength-specific frequency ranges support system-level RF planning
  • Wavelength-specific scan angles support predictable optical beam steering
  • Horizontal input and vertical output polarization supports defined optical integration
  • Suitable for OEM laser systems requiring controlled NIR beam positioning
  • Supports optical scanning applications using 750nm, 850nm, 900nm or 1064nm laser sources
  • Defined bandwidth uniformity supports consistent beam control across the operating range
  • Designed for specialist photonics platforms where wavelength flexibility and aperture size are important
