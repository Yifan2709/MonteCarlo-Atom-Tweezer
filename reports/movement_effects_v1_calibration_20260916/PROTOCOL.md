# 计算前冻结的诊断和比较规则

基准分支：movement_effects_v1，GitHub API 与 git fetch 均核实 c4775da561be0bf746448c52c5d2a5228937fbdd。历史审计保留。新代码、计算和图均保存独立产物，不修改参考数据。

主要目标固定为四组**实验散点**等组权重的均方误差平均值；每组先对自身全部散点平均，再对四组平均。密集拟合线只辅助绘图；200 us 拟合线到 n=31 截止。早期固定 n<=20，后期 n>20。误差条统计定义/样本量/相关性未知，不建立精确似然，不宣称统计通过。所有计算统一初态和实际位点池，不重置跨轮状态。

顺序：当前基线重算；仅 PSD 系数修正；仅手工轨迹修正；两项修正；声透镜关闭和逐段抖动关闭消融；从白噪声力模型导出的扩散与同局部平均注入对照；有限共同参数扫描；锁定后独立种子验证。不得按结果选随机种子、时间步、误差权重或参考区间。

筛查 seed=26091611；复筛 seed=26091612；锁定验证 seeds=26091621,26091622；物理基准 seed=26091631。初次筛查 N=256, dt=0.025 us；复筛 N>=1024；最后每种子 N=4096, dt=0.0125 us，另 dt=0.00625 us。计算时间允许缩减候选数但不得据视觉选择步长。

理论核查来源：[Savard et al., PRA 56 R1095 (1997)](https://jet.physics.ncsu.edu/publications/pdf/LaserNoise.pdf)，[Cs论文Methods](https://arxiv.org/html/2403.12021v4)。噪声定义 C(t)=integral_0^infinity S(f)cos(2pi f t)df，白噪声 C(t)=S delta(t)/2；由此 dv=(F/m)sqrt(S/2)dW。该力模型自然包含能量、各方向、时变深度依赖，机械运动仅由原时变势产生。
